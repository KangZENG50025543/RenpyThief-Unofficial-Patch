RenpyThief 非官方翻译补丁 v1.0.4.0｜测试版快速开始
============================================================

【先确认】
· 这是测试版：已关闭 Ren'Py 脚本层（不写、并会删除 game\00unofficial_bridge.rpy）。
· 目的：看原版会不会改走通用注入器 RenpyInjector，从而用你的 API。
· 如弹出「请选择翻译样式」，请选择「使用内嵌样式」。
· 「我的 API」使用补丁内置的干净 RenpyThief 6.7.8（6.7.8Origin），不读写你电脑上的原版目录。
· 官方免费额度仍请浏览你自己的 RenpyThief.exe，并按原版登录。
· 目前仅实测 RenpyThief 6.7.8 x86。
· 便携版必须完整解压，不能在 ZIP 内运行；不要把补丁解压进你自己的原版目录。

【第一次使用】
1. 打开“RenpyThief 非官方翻译补丁”。
2. 选择翻译来源：
   · 官方免费额度：点击“浏览…”，选择你自己的 RenpyThief.exe；不读取你的 API 凭据。
   · 我的 API：路径会自动变成内置 6.7.8，不用再选原版。选择 Provider，填写自己的凭据，建议先点“测试 API”。
     本机 Ollama / llama.cpp 等可选“本地模型”，API Key 可留空。
3. 保持“启用兼容性保护（推荐）”开启。
4. 点击启动。官方额度模式如出现登录页，请按原版要求登录。
5. 必须等到补丁显示“已就绪，可以拖入游戏”。
6. 再把游戏拖入 RenpyThief。Ren'Py 游戏若弹出「请选择翻译样式」，请选「使用内嵌样式」。
7. 打开任务管理器，看有没有 RenpyInjector-x86.exe；控制台是否出现 Routed generic injector plaintext。

【这次测试怎么判断】
· 有 RenpyInjector，且游戏出现中文：通用明文路由可能对 Ren'Py 也成立。
· 没有 RenpyInjector、只有内嵌 Hook、游戏仍是原文：原版没改走通用注入器，还不能废脚本层。
· Ren'Py 暂时没有中文是预期之一，不代表 1.0.3 正式版坏了。

【切换线路】
先关闭游戏和 RenpyThief，再回到补丁选择另一线路并重新启动；不支持热切换。

【常见故障】
· 提示 RenpyThief.exe 无效：这只会出现在官方额度模式。请选择原版主程序，不要选快捷方式或游戏 EXE。
· API 测试失败：检查密钥、余额/配额、模型名、平台权限和网络；不要公开密钥。
· 本机模型无译文：确认 Ollama 等服务已在 127.0.0.1 运行，且模型名与已加载模型一致。
· 端口 19899 被占用：关闭旧补丁、Bridge 或其他占用进程后重试。
· 弹出 no Qt platform plugin could be initialized：请改用本版本，不要把系统 Qt 拷进原版目录。
· 一直未就绪：关闭全部相关进程，从补丁重新启动。官方额度模式需完成原版登录。
· SmartScreen/安全软件警告：本程序尚未代码签名；请只从项目 GitHub Release
  下载并核对 SHA256SUMS.txt，不要全局关闭安全软件。

需要更多说明：安装版打开开始菜单中的“使用说明”；便携版阅读 README.md。
报告问题：在 GUI 点击“打开诊断目录”，仅提交已人工检查、脱敏的相关日志。
