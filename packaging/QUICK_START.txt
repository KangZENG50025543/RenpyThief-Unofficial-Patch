RenpyThief 非官方翻译补丁 v1.0.0｜快速开始
============================================================

【先确认】
· 本补丁不包含 RenpyThief；目前仅实测 RenpyThief 6.7.8 x86。
· 官方免费额度仍按原版登录；「我的 API」不再依赖官方会话接口。
· 本补丁不代替原版付费授权，也不会把翻译静默切到官方服务。
· 便携版必须完整解压，不能在 ZIP 内运行；补丁不要放进原版目录。

【第一次使用】
1. 打开“RenpyThief 非官方翻译补丁”。
2. 点击“浏览…”，选择你自己的 RenpyThief.exe。
3. 保持“启用兼容性保护（推荐）”开启。
4. 选择翻译来源：
   · 官方免费额度：不读取你的 API 凭据。
   · 我的 API：选择 Provider，填写自己的凭据，建议先点“测试 API”。
     本机 Ollama / llama.cpp 等可选“本地模型”，API Key 可留空。
5. 点击启动。官方额度模式如出现登录页，请按原版要求登录。
6. 必须等到补丁显示“已就绪，可以拖入游戏”。
7. 再把游戏拖入 RenpyThief。

【切换线路】
先关闭游戏和 RenpyThief，再回到补丁选择另一线路并重新启动；不支持热切换。

【常见故障】
· 提示 RenpyThief.exe 无效：请选择原版主程序，不要选快捷方式或游戏 EXE。
· API 测试失败：检查密钥、余额/配额、模型名、平台权限和网络；不要公开密钥。
· 本机模型无译文：确认 Ollama 等服务已在 127.0.0.1 运行，且模型名与已加载模型一致。
· 端口 19899 被占用：关闭旧补丁、Bridge 或其他占用进程后重试。
· 一直未就绪：关闭全部相关进程，从补丁重新启动。官方额度模式需完成原版登录。
· 显示“更新保护未确认”：20 秒内没有观察到已知版本检查，补丁会继续启动，
  但这不表示保护已经成功；钩子仍会拦截之后出现的已知版本接口。
· SmartScreen/安全软件警告：本程序尚未代码签名；请只从项目 GitHub Release
  下载并核对 SHA256SUMS.txt，不要全局关闭安全软件。

需要更多说明：安装版打开开始菜单中的“使用说明”；便携版阅读 README.md。
报告问题：在 GUI 点击“打开诊断目录”，仅提交已人工检查、脱敏的相关日志。
严禁上传 API Key、Cookie、账号、完整游戏文本、原版程序或游戏文件。
